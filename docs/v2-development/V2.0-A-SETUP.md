# V2.0-A 隔离环境运行说明

本阶段只有工程基础，不包含用户管理、RBAC、分类、附件或V2流程业务。保留V1联调18080和正式8080，不能为运行测试停止它们。

## 环境

JDK21、Maven3.9、PostgreSQL17.6。Flyway11.7.2由Boot3.5.16管理，新增core和PostgreSQL插件；未引入Hibernate。数据库用户需有新建测试库及新库DDL权限，不在脚本保存凭据。建议个人开发角色只授予隔离库权限；本机原角色使用信任/pgpass时可不提供密码，非此模式必须设置V2_DB_PASSWORD。

在仓库根PowerShell：

```powershell
$env:V2_DB_USER = '自己的数据库用户名'
$secureV2DbPassword = Read-Host '隔离库数据库密码（本机trust/pgpass可跳过这两行）' -AsSecureString
$env:V2_DB_PASSWORD = [System.Net.NetworkCredential]::new('', $secureV2DbPassword).Password
powershell -ExecutionPolicy Bypass -File scripts/prepare-v2.ps1 -PsqlPath (Get-Command psql).Source -IncludeRegression
```

固定创建以下库，已存在只跳过，不删除/重建：

|数据库|用途|
|---|---|
|dorm_repair_v2_dev|V2开发；启动才执行受保护业务迁移|
|dorm_repair_v2_test|V2 profile真实HTTP测试|
|dorm_repair_v2_test_legacy|合成V1接管/漂移测试；测试可重置此库的public/history schema|
|dorm_repair_v2_test_failure|空库/事务故障/校验和测试；测试可重置此库的public/history schema|
|dorm_repair_v2_test_v1|全部V1 A/B/C/D正常场景专用回归，不复用18080联调库|
|dorm_repair_v2_test_rehearsal|合成历史1/2/3和V1引擎迁移回归|

-IncludeRegression仅为最后两库初始化既有V1显式引擎脚本和合成夹具；这是测试环境，与V2 Flyway业务迁移分开。已有表时不补建，若初始化中断需检查实际状态，不能自动清库。测试的重置只允许明确的test_legacy/test_failure，禁止dev和任何正式/旧联调库。

## 启动18081

单独生成V2密钥，环境变量名V2_JWT_SECRET，不读写JWT_SECRET或INTEGRATION_JWT_SECRET：

```powershell
$v2KeyBytes = New-Object byte[] 32
$v2KeyRng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
try { $v2KeyRng.GetBytes($v2KeyBytes) } finally { $v2KeyRng.Dispose() }
$env:V2_JWT_SECRET = [Convert]::ToBase64String($v2KeyBytes)
powershell -ExecutionPolicy Bypass -File scripts/start-v2.ps1
```

不要输出密钥，不提交到Git。启动脚本先检查18081，已占用就失败，不kill任何进程。v2-dev固定127.0.0.1:18081和dev库，Flowable engine/自动DDL/async executor/workflow写入都关闭。测试可用随机端口；禁止8080或18080。

基础接口GET /api/v2/system/info，需要现有JWT认证。未带Token应返回V2格式401和X-Request-Id。新开发库不自动创建默认账号，用户管理在V2.0-B；自动测试自行创建仅测试库合成账号并真实登录。不要把已有正式账号密码复制到这里。

## 完整自动测试

```powershell
powershell -ExecutionPolicy Bypass -File scripts/test-v2.ps1
```

包含全部V1自动回归和新增V2基础测试；HTTP使用随机127.0.0.1端口，随机测试密钥只在内存。失败不删除测试、不降低断言。日志和Surefire报告留在backend/target，不能提交含运行账号或响应的产物。

## 基础契约

- GET /api/v2/system/info：apiVersion、stage、businessMigrationVersion、workflowEnabled；不暴露数据库URL/用户/密钥。
- V2错误：status/code/message/requestId/fieldErrors；400/401/403/404/409/503统一，未知异常500不泄露详情。V2 CORS为明确来源白名单且允许/暴露X-Request-Id；V1规则不变。
- V2Id显式序列化为十进制字符串；禁止给全局Long注册字符串serializer，V1数字ID不变。
- V2Page为items/page/size/total，page>=0、size1..100，offset用long。它不代替Repository SQL分页与数据权限。
- 本阶段只允许GET基础信息；其他/api/v2路径默认deny，不能当作已实现RBAC或用户接口。

迁移原理和禁止baseline/clean/repair的边界见V2.0-A-MIGRATIONS.md。后续开发等人工验收，不自行进入B。
