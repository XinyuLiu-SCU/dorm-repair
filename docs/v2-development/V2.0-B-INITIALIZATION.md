# V2.0-B 首个管理员安全初始化

仅适用于空的dorm_repair_v2_dev，固定127.0.0.1:5432。不提供HTTP初始化端点，不接受命令行密码参数，不从正式库复制数据。当前开发库不自动生成默认管理员；初始凭据由操作者安全交互或专用环境变量提供。

## 先决条件

1. 在feature/v2-development，按A说明设置V2_DB_USER/V2_DB_PASSWORD；环境密码不写配置、不入Git。本机trust/pgpass可省略密码变量。
2. v2-dev至少已成功执行V3；当前18081如已由本轮B服务启动，无需重复启动。否则先设置独立V2_JWT_SECRET并执行scripts/start-v2.ps1。不要停止8080/18080。
3. 开发库sys_user必须为空；已有用户/无初始化标记也拒绝，不把初始化当找回密码或覆盖账号的后门。

## 推荐：控制台隐藏输入

```powershell
powershell -ExecutionPolicy Bypass -File scripts/initialize-v2-admin.ps1
```

输入自己选择的合成管理员用户名及初始密码（不回显）。用户名3–50位英数/下划线/点/横杠，初始密码至少12字符且最多72 UTF-8字节。real_name固定为“合成开发管理员”，不录入实际住户资料。

若IDEA或重定向终端没有Java Console，可在本机PowerShell安全读取后放入专用进程环境，命令历史不含实际密码：

```powershell
$env:V2_BOOTSTRAP_ADMIN_USERNAME = Read-Host '合成管理员用户名'
$bootstrapSecretInput = Read-Host '初始密码' -AsSecureString
$env:V2_BOOTSTRAP_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new('', $bootstrapSecretInput).Password
try {
    powershell -ExecutionPolicy Bypass -File scripts/initialize-v2-admin.ps1
} finally {
    Remove-Item Env:V2_BOOTSTRAP_ADMIN_PASSWORD -ErrorAction SilentlyContinue
    Remove-Item Env:V2_BOOTSTRAP_ADMIN_USERNAME -ErrorAction SilentlyContinue
}
```

不要把这些值贴入聊天、报告、.http或Git文件。工具只输出INITIALIZED/ALREADY_INITIALIZED及ID，不输出密码/哈希/Token。

## 保护与重复执行

- 运行前复核真实连接URL/catalog/产品，仅dev；正常CLI不能切换到TEST或正式库。测试使用包内验证入口，仅针对受保护V2测试库构造合成夹具。
- 在事务内先锁system_guard，再检查已初始化标记和用户数；初始ADMIN种子必须完整，初始化后必须存在有效全量授权管理员。
- 第一次写入BCrypt哈希、明确角色关联、初始化标记及脱敏审计，同成同败。
- 同名重复返回ALREADY_INITIALIZED，**不改密码、ID、版本或角色**；不同用户名再次初始化拒绝。即使提交不同密码也不会覆盖旧密码。
- 并发同名初始化只有一次创建，另一调用识别已完成，不“最后写入者覆盖”。若已有账号但没有合法标记，工具拒绝；需要另行批准恢复方案，不删除标记强行重跑。
- 初始化后若该账号被正常停用，重复初始化不会启用它。通过另一授权管理员管理；不可用初始化绕过停用/密码策略。

## 验证

使用操作者设置的凭据POST /api/v2/auth/login，再GET /api/v2/auth/me，确认permissions含全部当前10项。不要在终端直接打印accessToken响应；将Token短暂保存在本地变量/请求工具私有变量。

真实PostgreSQL自动测试已覆盖首次初始化、弱密码回滚、重复不覆盖、不同用户名拒绝、已有用户拒绝、并发只创建一次和DEV/TEST目标限制。本轮不擅自选择或保存你将用于人工验收的管理员密码；请显式执行此步骤。
